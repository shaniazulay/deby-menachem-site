# דבי מנחם – אתר תדמית

אתר סטטי (HTML/CSS/JS ללא שלב build), מבוסס על עיצוב ה-Figma "דבי לקלוד":
- דסקטופ – פריים `4:20` (1440px)
- מובייל – פריים `119:1095` (390px)

## מבנה
| קובץ | תפקיד |
|---|---|
| `index.html` | כל תוכן הדף (RTL, עברית) |
| `styles.css` | עיצוב: ‎≥1100px קומפוזיציית הדסקטופ (מוקטנת כיחידה אחת בין 1100–1440), ‎<1100px עיצוב המובייל |
| `main.js` | תפריט מובייל, אקורדיון שאלות, חיצי המלצות, טופס → הודעת וואטסאפ |
| `assets/` | אייקונים ו-SVG מה-Figma, `assets/img/` תמונות WebP מכווצות |

## הרצה מקומית
```bash
npm run dev
```
ואז לפתוח http://localhost:3000

## העלאה ל-GitHub

git init

## העלאה ל-Vercel
ב-Vercel: **Add New → Project → Import** את הריפו. אין צורך בהגדרות – `vercel.json` כבר מגדיר אתר סטטי בלי install/build.
